模型接口

留空 API Key 即可使用离线演示模式。iPhone 原生壳内走 Swift 网络桥，不受浏览器跨域限制；网页版若直连被 CORS 拦截，把 Base URL 换成自己的代理地址即可。

数据

所有数据只存在本机（localStorage / App 沙盒），不会上传到任何服务器。

安装到 iPhone 主屏幕

在 Safari 打开本页 → 点底部「分享」 → 选「添加到主屏幕」，即可全屏运行，像原生 App 一样有独立图标。若你是用下面的 Xcode 工程编译的原生壳，这一段可忽略。
